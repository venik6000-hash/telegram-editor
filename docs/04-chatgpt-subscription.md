# Подключение личной подписки ChatGPT

Редакция не принимает и не хранит OpenAI API-ключ. Она запускает Codex на этом же компьютере и требует вход именно через ChatGPT. Поэтому каждый пользователь подключает собственную учётную запись и использует лимиты, доступные его плану.

## Подключение

1. Установите Codex Desktop или Codex CLI.
2. В терминале выполните:

   ```sh
   codex login
   ```

3. В открывшемся браузере войдите в нужную учётную запись ChatGPT и завершите вход.
4. Проверьте, что авторизация активна:

   ```sh
   codex login status
   ```

5. Запустите редакцию. В ней откройте состояние Codex: оно должно показать, что подключена подписка ChatGPT.

Официальная документация OpenAI подтверждает, что Codex CLI и десктоп-клиент поддерживают вход через ChatGPT для доступа по подписке; `codex login` открывает браузерный поток входа. [OpenAI Docs: Authentication](https://developers.openai.com/docs/auth)

## Важно

- Не вставляйте API-ключ в настройки редактора: такого поля нет. Код запуска принудительно выбирает вход ChatGPT, а не оплату по API.
- Лимиты и доступные возможности зависят от текущего плана и правил ChatGPT. Редакция не делает генерацию безлимитной и не переносит чужую подписку.
- Если статус сообщает, что входа нет, повторите `codex login`; если аккаунт не подходит для нужной возможности, используйте план или окружение, в котором Codex доступен.
- На удалённой или безэкранной машине используйте `codex login --device-auth`, если этот метод доступен в настройках аккаунта. Не копируйте и не публикуйте файл с токенами авторизации.

API-ключ — отдельный способ оплаты по использованию; он не является подпиской ChatGPT. OpenAI описывает это различие в [официальной документации по аутентификации](https://developers.openai.com/docs/auth).
