# Старт с Codex: установка и интервью

Этот сценарий рассчитан на Codex в приложении ChatGPT для macOS/Windows или Codex CLI. Обычный чат ChatGPT в браузере не может устанавливать и запускать локальные приложения по одной ссылке.

## Один промпт для нового пользователя

Создайте новую локальную задачу в Codex и отправьте сообщение целиком:

```text
Установи и запусти локально этот проект:
https://github.com/venik6000-hash/telegram-editor

Клонируй его в отдельную папку, не используй API-ключ OpenAI и проверь вход
через мою учётную запись ChatGPT. После запуска не генерируй посты: сначала
проведи со мной интервью для профиля первого Telegram-проекта. По очереди
собери tone of voice и визуальный формат, следуя AGENTS.md из репозитория.
В конце верни готовые блоки «Голос» и «Визуальный стиль», покажи их мне и
сохрани в редакции только после моего явного подтверждения. Не проси токен
Telegram в чате и не публикуй ничего.
```

Одной голой ссылки недостаточно: она не объясняет агенту, что нужно клонировать проект, открыть локальное приложение и начать интервью. Промпт выше — минимальная надёжная команда для этого сценария.

## Что сделает агент

1. Создаст отдельную папку, клонирует репозиторий и проверит Node.js 24+.
2. Проверит `codex login status`. Если входа нет, направит владельца к `codex login` и входу в собственную учётную запись ChatGPT. API-ключ не нужен.
3. Запустит штатный файл для macOS, Windows или Linux и откроет `http://127.0.0.1:4317`.
4. Поможет создать владельца и первый пустой проект в интерфейсе.
5. Задаст вопросы о читателях, цели, тоне, ограничениях, примерах и структуре текста, затем — о назначении визуала, композиции, палитре, типографике, референсах и запретах.
6. Сформирует два отдельных блока для профиля и попросит подтвердить их перед сохранением.

Telegram подключается только после этого: владелец сам вводит токен отдельного бота в поле локальных настроек. Он не должен попадать в диалог, исходники или GitHub.

## Если Codex недоступен

Установите Codex, войдите в свою учётную запись ChatGPT и повторите промпт. Официальная документация OpenAI подтверждает, что Codex в десктопном приложении и CLI поддерживает локальную работу после входа через подписку ChatGPT; она также описывает локальные setup-скрипты для новых worktree.
