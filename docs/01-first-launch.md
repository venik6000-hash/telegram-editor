# Первый запуск

## До запуска

Нужны:

- Node.js 24 или новее (`node --version`);
- установленный Codex с входом в личный ChatGPT — [инструкция](04-chatgpt-subscription.md);
- браузер и интернет для генерации и публикации;
- права владельца на Telegram-канал или группу, если планируется публикация.

Редакция не требует `npm install`: она использует возможности Node.js 24. Распакуйте или клонируйте папку в постоянное место, где у пользователя есть права на запись.

## Запуск

macOS: дважды щёлкните `Запустить_редакцию.command`.

Windows: дважды щёлкните `Запустить_редакцию.cmd`.

Linux: в терминале из корня папки выполните:

```sh
sh Запустить_редакцию.sh
```

Откройте `http://127.0.0.1:4317`. Не закрывайте окно запуска: пока оно открыто, редакция и запланированные публикации работают. Закрытая вкладка браузера сервер не останавливает.

При первом входе создайте владельца. Пароль должен быть не короче 12 символов. Он защищает локальный доступ к редакции; не используйте один пароль для нескольких людей.

## Первый проект

Откройте настройки проекта и заполните:

1. название, аудиторию и язык;
2. рубрики — хотя бы одну;
3. «Голос» по [шаблону](../templates/tone-of-voice.md);
4. «Визуальный стиль» по [шаблону](../templates/visual-style.md);
5. примеры утверждённых публикаций и дополнительные правила, если они есть.

В каждом новом проекте эти поля независимы. Не смешивайте правила нескольких брендов в одном профиле: создайте отдельный проект.

## Где хранятся данные

- `data/editor.sqlite` — карточки, история, пользователи и сведения о публикациях;
- `data/media/` — загруженные и сгенерированные изображения;
- `data/projects/<проект>/attachments/` — файлы, приложенные для агента, и картинки, которые он взял с сайтов;
- `data/projects/<проект>/jobs/` — рабочие папки заданий агента, в том числе скачанные с сайтов кандидаты;
- `data/private/` — настройки Telegram, включая токены;
- `data/backups/` — ежедневные архивы без токенов.

Папка `data/` создана для конкретной установки и уже исключена из Git. Её не надо включать в публичный репозиторий или отправлять другим людям. Для переноса сделайте резервную копию из интерфейса, а секретную папку сохраните отдельно в защищённом месте.
