# Проверка перед публикацией в open source

## До первого коммита

1. Убедитесь, что в репозиторий не попала папка `data/`, архивы, скриншоты с личными данными и локальные заметки.
2. Проверьте, что в коде, README и примерах нет токенов Telegram, паролей, API-ключей, персональных ссылок или реальных данных подписчиков.
3. Прочитайте [LICENSE](../LICENSE) и при необходимости замените строку copyright на владельца проекта до первого публичного релиза.
4. Прочитайте [AGENTS.md](../AGENTS.md): инструкции запрещают агентам просить или сохранять секреты.

Пример локальной проверки на случайно попавшие секреты:

```sh
rg -n --hidden -g '!data/**' -g '!node_modules/**' '(?:\d{6,}:[A-Za-z0-9_-]{20,}|OPENAI_API_KEY|telegram.*token)' .
```

Результат нужно просмотреть вручную: название переменной в исходном коде не является секретом, а похожая строка с реальным токеном — причина остановить релиз и отозвать токен.

## Минимальная проверка релиза

```sh
node --version
npm test
```

После запуска проверьте вручную:

- при первом входе создаётся новый владелец;
- базовый проект называется «Мой проект»;
- в «Настройках проекта» есть поле токена, но старый токен нигде не показывается;
- пустой голос или визуальный стиль останавливает соответствующую генерацию с просьбой заполнить профиль;
- «Проверить подключение» Telegram не публикует сообщение;
- папка `data/` остаётся неотслеживаемой.

## Материалы с сайтов

Если в инструкции агенту есть адрес сайта, страницу открывает сама редакция, а не агент: у агента нет shell, и прочитанная страница не может заставить его прочитать локальные файлы или токены. Правила загрузки:

- только `http` и `https`, без логина и пароля в адресе, не больше трёх адресов за запуск;
- адреса локальной и частной сети отклоняются, в том числе когда публичное имя указывает на такой адрес — проверка выполняется в момент соединения, после каждого перенаправления;
- ограничения: страница до 3 МБ, картинка до 8 МБ, SVG до 1 МБ, всего до 30 МБ, не больше 8 картинок и 90 секунд; остановка задания прерывает загрузку;
- SVG очищается от скриптов, стилей и внешних ссылок и переводится в PNG штатной утилитой `sips` на macOS; на других системах SVG пропускается;
- текст страниц передаётся агенту как данные в формате JSON, а инструкция пользователя помечается случайной меткой запуска, поэтому страница не может выдать себя за неё.

При проверке релиза убедитесь, что инструкция со ссылкой на `http://127.0.0.1:4317` или адрес домашней сети не открывается.

## Что не стоит обещать в README релиза

- неограниченную генерацию по любой подписке ChatGPT;
- работу расписания при выключенном компьютере;
- автоматическое добавление пользователей в Telegram;
- безопасный публичный HTTP-доступ без VPN или HTTPS-прокси.

Если редакцией пользуется небольшая команда, сначала создайте пользователей локально. Для доступа из внешней сети используйте частную VPN или HTTPS-прокси; не выставляйте локальный сервер в интернет без отдельной модели безопасности.
