# Профиль проекта: текст и визуал

Редакция не хранит единый глобальный tone of voice. У каждого проекта свой профиль, а агент получает его заново при каждой задаче. Это защищает от ситуации, когда публикации для разных каналов звучат одинаково.

## Как заполнять поля

| Поле в редакции | Что в нём должно быть |
| --- | --- |
| Аудитория | Роль читателя, уровень знаний, контекст и задача, которую решают посты. |
| Голос | Готовый блок из [шаблона tone of voice](../templates/tone-of-voice.md). |
| Визуальный стиль | Готовый блок из [шаблона визуального стиля](../templates/visual-style.md). |
| Примеры | 2–5 утверждённых текстов или ссылки на них; они задают только форму, не факты. |
| Дополнительные правила | Контентные границы, обязательные источники, юридические ограничения и правила рубрик. |

## Если профиль нужно собрать с агентом

Откройте диалог с агентом в Codex или ChatGPT, дайте ему [AGENTS.md](../AGENTS.md) и отправьте один из запросов ниже.

Для тона:

```text
Помоги настроить tone of voice для Telegram-проекта. Действуй по разделу
«Когда просят настроить tone of voice» из AGENTS.md: сначала задай только
нужные вопросы, затем верни один готовый блок «Голос» для вставки в редакцию.
Не выдумывай факты и не публикуй ничего.
```

Для визуала:

```text
Помоги настроить визуальный формат для Telegram-проекта. Действуй по разделу
«Когда просят настроить визуальный формат» из AGENTS.md: сначала задай только
нужные вопросы, затем верни один готовый блок «Визуальный стиль» для вставки
в редакцию. Не создавай картинку, пока формат не согласован.
```

При следующем запросе приложите ответы, ссылки на разрешённые референсы и, при наличии, 2–5 одобренных публикаций. Агент должен различать утверждённые правила, предложения и неизвестные данные.

## Как профиль влияет на генерацию

Текстовая ветка использует язык, аудиторию, голос, примеры и дополнительные правила. Визуальная ветка использует визуальный стиль и смысл выбранного поста. Если поле «Голос» или «Визуальный стиль» пустое либо агент не может выполнить требование без догадок, задача должна остановиться с коротким вопросом. Заполняйте профиль и запускайте задачу заново; это намеренная проверка качества, а не ошибка подключения.
