# Подключение Telegram-бота

Редактор публикует от имени отдельного Telegram-бота. Создайте бота специально для этой редакции: не используйте один токен между несвязанными проектами.

## 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Выполните `/newbot`, задайте имя и username.
3. BotFather покажет токен вида `123456:ABC…`. Скопируйте его во временный защищённый буфер.

Токен — это пароль бота. Если он оказался в чате, заметке или публичном коммите, отзовите его через BotFather и выпустите новый.

## 2. Добавьте бота в место публикации

### Обычный канал

Добавьте бота администратором канала и дайте право публиковать сообщения. В редакторе выберите «Обычный канал» и укажите `@username` или ссылку вида `https://t.me/username`.

### Группа с темами

Включите в супергруппе темы, добавьте бота администратором с правом публиковать сообщения. В редакторе выберите «Форум с темами». Укажите числовой ID группы, который начинается с `-100`, и для каждой рубрики укажите ID темы.

Для ссылки на тему вида `https://t.me/c/1234567890/42` используйте ID группы `-1001234567890` и ID темы `42`. Копируйте ссылку на саму тему, а не на произвольный пост внутри неё.

## 3. Введите токен в редактор

1. Выберите нужный проект.
2. Откройте «Настройки проекта».
3. Вставьте токен в «Токен отдельного бота».
4. Выберите тип адресата и заполните канал или группу/темы.
5. Нажмите «Сохранить», затем «Проверить подключение».

Проверка использует Telegram `getMe`, `getChat` и `getChatMember`. Она не публикует тестовое сообщение. После удачной проверки редакция показывает только факт наличия токена, а не сам токен.

Редактор не меняет webhook, не читает `getUpdates` и не добавляет пользователей в канал или группу. Он отправляет только согласованную сохранённую версию поста по нажатию пользователя или по локальному расписанию.

## Если публикация прервалась

Не нажимайте «Опубликовать» повторно вслепую. Сначала проверьте канал/группу: Telegram мог принять часть сообщений. Если всё пришло, зафиксируйте ID сообщений через сверку в карточке. Если не пришло, исправьте причину и создайте новую версию для публикации.
